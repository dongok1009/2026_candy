## 1. 시간 및 데이터 참조 원칙 (Timing & Data)

### 1-1. 데이터 참조 원칙 (Data Reference)
*   **확정 데이터만 사용:** 시그널 판단 시점 `T`에서 사용 가능한 데이터는 오직 `봉의 종료 시간(EndTime) <= T`인 데이터뿐이다.
*   **절대적 인덱스 탐색 (Iron Rule):** 단순 `Index - 1` 연산을 지양하고, 반드시 `findLastIndex` 등을 통해 `k.time + 주기 <= T` 조건을 만족하는 가장 최근 인덱스를 찾는다. (인덱스 오차 원천 차단)
*   **지표 계산:** 모든 이평선, MACD, Stoch RSI 등은 위 방식에 의해 선택된 확정 인덱스의 값을 기준으로 한다.

### 1-2. 시그널 발생 원칙 (Signal Decision)
*   **UI 설정 동기화:** 대시보드(UI)의 각 타임프레임별(5m, 1h, 1d) 체크박스 설정은 `overrideRules`를 통해 엔진에 전달되며, 이를 최우선으로 적용한다.
*   **AND 조건 필터링:** 특정 방향(LONG/SHORT)으로 진입하기 위해서는 해당 방향에 **체크된 모든 조건**이 동시에 충족되어야 한다. (하나라도 미충족 시 `hold`)
*   **방향 일치성:** 5m, 1h, 1d의 필터링 결과가 모두 동일한 방향일 때만 최종 시그널을 발생시킨다.

### 1-3. 진입 실행 원칙 (Entry Execution)
*   **진입 시작:** 시각 `T`에 결정된 신호(T-1 데이터 기반)는 **해당 분봉인 `T`**부터 즉시 진입 조건(지정가/시장가 도달 여부)을 체크한다.
*   **프로세스:** `T-1` 데이터 확정 -> `T` 시점 시작과 동시에 신호 인지 -> `T` 분봉 내에서 진입 시도.

## 2. 하위/상위 타임프레임 연동 원칙 (MTF Rules)

### 2-1. 상위 봉(5m, 1h, 1d) 참조
*   **확정봉 기준:** 5분봉, 1시간봉 등을 참조할 때도 현재 진행 중인 봉이 아닌, **이미 마감이 완료된(Closed)** 상위 봉의 최종 지표값을 사용한다.
    *   예: 09:11 시점에서는 09:10에 마감된 5분봉 데이터를 사용한다.
